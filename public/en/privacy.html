Privacy

Short and plain.

We don't collect anything from you. Below, one by one: what each tool and this site keep and where, and when and where they go online.

Last updated: November 13, 2026

In short

  • No account: none of our tools asks you to sign up, give an email or log in.
  • No telemetry, no ads, no usage analytics.
  • No cookies on this site, no visitor tracking.
  • Everything you collect in our tools stays on your computer.

Catail

What it keeps on your computer

  • Settings: in %APPDATA%\Catail\settings.json.
  • Queued images: in the temp folder (%TEMP%\catail\). They are deleted when the app closes; anything left behind is cleared the next time it starts.
  • Queued files: only the file's path is kept. Catail never copies, changes or deletes the original.

The clipboard

Catail only watches the clipboard while text mode is on; what you copy then joins the queue. Copies that password managers mark as "keep out of history" are skipped. After pasting, whatever was on your clipboard before is put back.

The two moments it goes online

  • Checking for a new version: at startup it reads the release file on GitHub. That's an ordinary download request; nothing about you is sent, though, as with any connection, GitHub sees your IP address.
  • Translation: only when you press Translate is the text you picked sent to Google Translate. If you don't press it, no text leaves your computer.

Apart from these, Catail doesn't go online. Text recognition (OCR) uses Windows' own engine, and QR codes are read on your device. If you choose to open the address in a QR code, your browser opens it; Catail doesn't visit it itself.

This website

  • Cookies: none. No visitor counter, ads or tracking code either.
  • What it keeps in your browser: the cat you picked, plus the release list and the GitHub counts (a cache of a few minutes, to make fewer requests). All of it stays in your browser's own storage; none is sent to us.
  • Outside addresses it connects to: Google Fonts for the typefaces; GitHub for the release list and the download and star counts. Download buttons fetch the file straight from GitHub.
  • Server logs: like any website, the server hosting this site may keep technical access logs (IP address, time, page asked for). We don't use them for ads or profiling.

Questions and changes

If this text changes, we update its date and say so in the release notes. If something's wrong, tell us on GitHub. All the code is open, so you can check all of the above yourself.
